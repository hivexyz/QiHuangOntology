## 4. 开放问题

- `moderation` 接口最终是否允许 API client 直接调用，还是只允许登录用户调用。如果允许 API client，需要补一套独立的审核资源权限规则。
- `knowledge_cards` 是不是计划完全移除，还是长期保留为 legacy snapshot。如果长期保留，必须把其角色限定为离线兼容资产，而不是运行时事实补洞来源。
- OWL importer 是面向 demo 数据、标准医学本体，还是明确面向中医本体。不同目标决定映射策略是否能继续使用当前 heuristic。
